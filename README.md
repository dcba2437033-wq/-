# 提香美术 AI 内容总监

面向美术培训机构的轻量内容运营工具原型。

## 当前功能
- 短视频脚本初稿
- 活动策划初稿
- 家长咨询话术
- 招生漏斗数据复盘

> 当前版本是模板驱动的演示原型，不会调用大模型，也不会保存客户个人信息。

## 在 Streamlit Community Cloud 部署
1. 登录 https://share.streamlit.io/
2. 选择 New app。
3. 选择 GitHub 仓库 `dcba2437033-wq/-`，分支 `main`，主文件 `app.py`。
4. 点击 Deploy。

注意：仓库名称 `-` 不够清晰，建议后续在 GitHub 创建名为 `tixiang-art-ai-director` 的新仓库，再将这些文件复制过去。若平台不接受该仓库名称，可先新建正常命名仓库后部署。
